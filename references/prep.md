# 备课模式（Prep Mode）

`SKILL.md` 里的「流程 B」用本文件。**备课是一次性阶段，不是每次会话都做。**

---

## 为什么必须有这一步

源材料的天然形态 **≠** 教学需要的形态。

| 维度 | 源材料（字幕 / 书 / 文档） | 教学需要 |
|---|---|---|
| 组织方式 | 线性叙述（按讲述顺序） | 依赖图（按学习顺序） |
| 粒度 | 一节几千字 | 一个原子点 |
| 冗余 | 口语重复、跑题 | 极少 |
| 例子 | 混在轶事里 | 每点一个标准范例 |
| 题目 | 通常没有 | 预考 / 练习 / 迁移 |
| 答案 | 通常没有 | 必须有，且可核对 |
| 误解 | 隐含 | 显式 |
| 前置 | 不声明 | 必须声明 |

两个致命后果：

1. **没有题目** → 提取练习和掌握闸门完全转不起来，skill 退化成"AI 讲课"。
2. **没有答案** → AI 只能自己生成题目和答案 → 容易把材料没说过的东西当结论教出去（**教幻觉**）。

**所以：材料能支撑「讲」，不代表能支撑「测」。备课就是补上「测」的部分，并且保证不编。**

├── map.md                     # 从所有 lesson.md 汇总的知识地图

## lesson.md 的结构（每个原子点一块）

11 个字段。**缺哪个就写「⚠️ 缺口」，不要留空，也不要编。**

```markdown
### P<编号> <名称>

**原子性**：只考一件事 ✓ / ✗（✗ 就必须拆）

**【材料原话】**
- 出处：<章节号 / 页码 / 时间戳>
- 要点：<忠实转述，不加自己的解释>

**【机制 / 为什么】**
- 材料给了 → 写出并标出处
- 材料没给 → `⚠️ 缺口：材料只断言现象，未给原因`
- 可选【外部补充】：<来源> —— 必须带来源，且明确标注为外部补充

**【前置】** <依赖哪个 P；材料未声明的必须在此标注「材料未声明，备课补充」>

**【标准范例】** 最小可复现的例子（不是场景描述，是能复算/能复现的）

**【常见误解】** 1. … 2. …

**【适用边界】** 什么情况下不成立 / 材料没交代的部分

**【预考题】** 学之前问的 1–3 题（必须是他此刻答不出的）

**【练习题 + 答案】** 2–4 题，难度递增

**【迁移题】** 换一个情境

**【掌握判定】** 能说清 / 能应用 / 能回忆 各自的具体标准
```

## 三条纪律（最重要）

### 1. 溯源

每个点必须能指回材料的 `章节号 / 页码 / 时间戳`。
**指不回去的内容 = 你自己编的。** 要么标注为外部补充，要么删掉。

### 2. 三分标记，绝不混

| 标记 | 含义 |
|---|---|
| `【材料原话】` | 材料明确说了 |
| `【外部补充】` | 材料没说，你补的（必须带来源） |
| `【待查证】` | 你不确定（例：疑为某文献所述，需核实） |

讲义里"老师说了 A"，和你"查到的文献说 A"，是两件事。混在一起教，学习者无法分辨。

### 3. 缺口写「缺」

材料没给机制、没给边界、没给答案，就明确写缺口。

> **宁可留白，也不要编一个像模像样的解释。**

这条比"填满所有字段"重要得多。

## 备课流程

1. **摸底**：读完材料，判断总长度、结构、可用信息（有无时间戳 / 章节号）。
2. **切原子点**：按"一个可测单元"切。一份 1–2 小时的材料，通常 **10–40 个点**。
   - 点太多 → 粒度太细，合并
   - 点太少 → 没真拆，重切
3. **画依赖图**：定前置关系。**材料几乎从不声明前置，这步必须自己推。**
4. **逐点填 11 个字段**，缺的标缺口。
5. **自检**（逐条过）：
   - [ ] 每个点都有前置、范例、误解、题目 + 答案？
   - [ ] 每道题的答案都能指回材料某处，或明确标为外部补充？
   - [ ] 有没有"我补充了但没标注"的内容？
   - [ ] 有没有为了凑字段而编出来的机制？（有就删）
6. **产出 `map.md`**：汇总所有点 + 状态列。
7. **与学习者对齐**：把地图给他看，确认范围、粒度、取舍。
   **这一步不能省**——否则会备一堆没人学的东西。

## 材料质量分级

| 级别 | 形态 | 备课难度 | 风险 |
|---|---|---|---|
| **A** | 结构化讲义（有章节、定义、习题、答案） | 低 | 低 |
| **B** | AI 改写的书 / 详细文档（有结构、无题） | 中 | 中 |
| **C** | 视频字幕 / 课堂转录（线性、口语、无题） | 高 | 高 |
| **D** | 只有题目、没有讲解 | 特殊 | 低（可反着用：先测后讲） |

**C 类必须做「清洗 + 切分 + 补题」，且所有补出来的内容都要标记。**
C 类如果有时间戳（如 `(参考时间: 21:24)`），一定要用起来——它是最可靠的溯源锚点。

---

## 防止备课失真

- **不要为了"填满 11 个字段"而编造机制。** 字段是清单，不是 KPI。
- 题目优先从材料里已有的例子反推；材料没有才自己造，并标注 `【外部补充】`。
- 某个点材料讲得太浅、撑不起一次会话 → **降级为「了解即可」**，不要硬教。
- 材料自相矛盾时，**原样记下矛盾**，不要擅自调和。

---

## 备课完成后的交接

备完不要直接开讲。先做三件事：

1. 展示 `map.md` 的地图（点数、依赖、缺口统计）
2. 说明**哪些是材料原话、哪些是外部补充、哪些是缺口**
3. 让学习者选**今天从哪个点开始**（默认按依赖顺序的第一个未掌握点）

然后进入 `SKILL.md` 的「流程 A」。
