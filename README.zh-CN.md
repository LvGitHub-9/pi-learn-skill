# learn — 带护栏的一对一学习教练（pi skill）

> 一个**不允许先讲解**的 AI 导师。
> 它逼你先输出，然后测你，然后把复习排进日程。

[English](README.md) | [中文](README.zh-CN.md)

这是一个 [pi](https://github.com/badlogic/pi-mono) skill。放进 skills 目录，它就把一次聊天
变成带持久状态的结构化辅导循环。

---

## 问题：为什么绝大多数「AI 教学」都失败

让 AI 教你一个东西，你会得到一份结构清晰、读起来很顺的讲解。读完你觉得懂了。一周后一个字
都复现不出来。

这背后有两个机制，而且只有一个跟 AI 有关：

**1. 流畅性错觉。**
读一份清楚的讲解，感觉像在学习。它不是。**看懂 ≠ 能提取。** 判断一个东西有没有进你的记忆，
唯一方法是尝试把它调出来——而讲课永远不会要求你做这件事。

**2. AI 拐杖效应。**
这一条现在有实测数据了。Bastani 等（2025，*PNAS*）做了近千名高中生的现场实验，对比两种
AI 导师：

| 组别 | 使用期间 | **撤走 AI 之后** |
|---|---|---|
| 裸 ChatGPT 式助手 | 成绩 **+48%** | **比从没用过 AI 的学生还差 17%** |
| 带学习护栏的导师 | 成绩 **+127%** | 无负面效应 |

无约束的访问让学生把模型当成了拐杖：用的时候表现更好，之后独立作答反而更差。而「护栏」——
苏格拉底式追问、拒绝直接交出答案——把负面效应完全消除了。

**所以失败的原因不是「AI 讲得不好」，而是「AI 讲了」。**

## 设计的来源

这个 skill 不是提示词技巧。它里面每一条规则都对应一个具体的研究结论。完整的证据基础（含
引用）在 [`references/methods.md`](references/methods.md)。

### 承重的那些发现

| 本 skill 中的设计决策 | 来源 |
|---|---|
| 学习者没尝试之前绝不讲解；永远先要一次回答 | Pan & Sana 2021, *JEP: Applied* —— 5 个实验、n=1573：预考优于后测 |
| 强制学习者用自己的话复述 | Dunlosky 等 2013, *Psych. Science in the Public Interest* —— 自我解释评为中等效用 |
| 讲完就测；每次会话必须测试收尾 | 同上 —— 实践测试是仅有的两个**高效**方法之一 |
| 用递增间隔的卡片排复习 | 同上 —— 间隔练习是另一个高效方法 |
| 小步呈现，讲一个点就停 | Sweller 等 2019, *Educational Psychology Review* —— 工作记忆容量有限 |
| 目标约 85% 正确率，超出 70–95% 就调整 | Wilson 等 2019, *Nature Communications* —— 对一大类学习算法，最优训练正确率约 85.87% |
| 未展示掌握就不前进 | Bloom 1984 —— 「一对一 + 掌握学习」才产生了著名的 2 sigma 效应 |
| 反馈必须说清 目标 / 现状 / 下一步；禁止表扬人 | Hattie & Timperley 2007, *Review of Educational Research* |
| 复习时交错主题——但单词表和说明文除外 | Brunmair & Richter 2019, *Psychological Bulletin* —— 交错对归纳学习有效，且收益受材料相似性制约 |
| 按任务复杂度调难度，而不是「越难越好」 | 2024, *Quarterly Journal of Experimental Psychology* —— 用「元素交互性」调和合意困难与认知负荷理论 |
| 绝不问「听懂了吗」 | Rosenshine 2012, *American Educator* —— 最无效的检查方式；有效教师检查**所有**学生 |
| 每条断言都要溯源；缺口必须显式标注 | 本仓库自己的 `references/prep.md` —— 见[备课模式](#备课模式当你手上有材料) |

### 本 skill 刻意**不做**的事

有几个流行说法没能通过证据检验：

| 流行说法 | 现状 |
|---|---|
| 学习风格（视觉型 / 听觉型 / 动觉型） | **已证伪。** 对学习结果无影响。（2026, *Journal of Educational Psychology*；2023, *Medical Science Educator*） |
| 成长型思维作为通用杠杆 | **已降级。** Sisk 等 2018, *Psychological Science* 两篇元分析（*k*=273, N=365,915）：整体效应很弱；收益主要出现在低社经地位 / 学业风险学生身上 |
| 重读和划线 | **低效。** Dunlosky 等 2013 —— 最常用的两种方法恰好是最没用的 |
| 「帮我总结一下」当学习方法 | **低效。** 总结被评级为低效；而且总结本身是一种**输出**，应该由学习者产出，不是 AI |

### 为什么 AI 导师这件事本身成立

Kestin 等（2025, *Scientific Reports*）做了随机对照实验：一个**用与课堂相同的教学法原则设计**
的 AI 导师，让学生**用更少时间学到两倍以上**，效应量 0.73–1.3 个标准差——已经接近 Bloom 的
2 sigma。

Wang 等（2024，Tutor CoPilot，900 名导师 / 1800 名学生）发现：AI 辅助**人类**导师能把学生
掌握率提升 4 个百分点，而在**原本最弱的导师组提升 9 个百分点**。AI 在人类最弱的地方帮助最大。

规律是一致的：**AI 被教学法约束时有用，不被约束时有害。**

## 它和「直接让 AI 教我」的区别

| | 常见的 AI 教学 | 本 skill |
|---|---|---|
| 谁先开口 | AI | **你**——预考是强制的 |
| 答案什么时候出现 | 立刻 | **在你尝试过之后** |
| 蒙对了怎么算 | 记为「会了」 | **追问理由** |
| 会话何时结束 | 讲完为止 | **通过一次测试** |
| 下周还记不记得 | 不管 | 间隔卡片 + 记录间隔 |
| 你带来的材料 | 塞进上下文，然后忘掉 | 先编译成**可测的教学包**，再开讲 |
| 它了解你多少 | 零，或仅限本次对话 | 持久化的**学生档案**（词汇量、知识边界、可用类比） |
| 它不知道的时候 | 编 | 明说，并记录缺口 |

## 这个 skill 具体怎么做的

### 8 条铁律

这些是**硬约束**，不是建议：

1. **绝不先给答案。** 你必须先猜、先说、先试——哪怕一定会错。
2. **一次只讲一小段。** 单次知识输出 ≤ 15 行，讲完**必须停下来提问**。
3. **绝不问「听懂了吗」。** 改为让他复述或做题。
4. 每个新概念必须走完整循环：预考 → 小段讲 → 自我解释 → 复述 → 做题 → 掌握判定。
5. **每次会话必须以一次测试结束。**
6. **答错时先问「你是怎么得出这个的」**——定位断点，不要直接给修法。
7. **不知道就说不知道。** 绝不编造事实或来源。
8. **只用学习者确认过的词汇和类比。** 用一个他不懂的领域打比方，等于**再加一层要学的东西**。
   （这条规则是一次真实失败之后加上的——见[实测记录](#实测记录真实发生过什么)。）

### 会话循环

```
0. 加载状态      学生档案 → 主题地图 → 到期卡片
1. 复习卡片      只给问题；学习者回答后自评 1–4
2. 预考          2–3 个他此刻答不出的问题。记录错误答案，先不纠正
3. 定位          只取一个原子点。检查前置。若基础词都不会，当场补 P0 改教那个
4. 讲授          ≤15 行，先给具体例子，然后 STOP 并提问
5. 自我解释      「这一步为什么成立？」「如果 X 变了会怎样？」
6. 复述          「合上材料，讲给一个 12 岁的人听。」然后问：「这个解释哪里最薄弱？」
7. 练习          难度递增；回去对预考答案；反馈用 目标/现状/下一步
8. 掌握闸门      能说清 + 能应用 + 能回忆，正确率约 85%。否则定位断点，只重教那一点
9. 记录          更新地图、卡片、会话日志、学生档案
```

其中干活最多的是**第 6 步**那个追加问题——*「这个解释哪里最薄弱？」*。
实测中，学习者靠这一问在**错误观念成形之前**自己抓住了它——这是任何数量的 AI 讲解都做不到的。

### 备课模式（当你手上有材料）

如果你带来一份课程录音、一本教材或一份转写稿，这个 skill **不会**把它塞进上下文然后开讲。
它会先编译一份**教学包**：

```
source/<材料名>.lesson.md
```

每个原子点填 11 个字段：材料原话 + 出处、机制、前置、标准范例、常见误解、适用边界、预考题、
练习题**（含答案）**、迁移题、掌握判定。

有三条纪律，它们的每一条都对应一个具体的失败模式：

1. **溯源。** 每个点必须能指回章节号、页码或时间戳。指不回去的，就是你编的。
2. **三分标记。** `【材料原话】` / `【外部补充】` / `【待查证】`——绝不混。
   「老师说了 A」和「我在论文里读到 A」是两个不同的断言。
3. **缺口就写「缺口」。** 材料没解释**为什么**，就明说。
   **宁可留白，也不要编一个听起来像模像样的机制。**

理由很直接：**材料通常没有题目，也没有答案。** 没答案时 AI 会自己生成题目和答案——然后
开始**教一些材料从没说过的东西**。

### 学生档案

一个全局文件 `learner.md`，跨所有主题共享。每次会话开头必读。它**不是**「学习风格」问卷——
它记录的是你**实际会什么**：

- **知识边界**，分为**已确认**（测过）和**自评**（未验证）。自评永远不能作为授课的前置假设。
- **术语表** —— 哪些词可以直接用，哪些必须先展开。
- **类比素材库** —— 你真正在行的领域。表格为空时，skill 被限制为只能使用生活化通用类比，
  **禁止**从任何专业领域借比喻。
- **校准记录** —— 长期跟踪「自评 vs 实测」，让 skill 学会该多大程度信任你的自我判断。

    └── due.py                # 从 cards.md 里挑出到期卡片（仅标准库）

```
data/learning/
├── learner.md                        # 全局档案（跨主题）
└── <主题>/
    ├── goal.md  map.md  cards.md
    ├── source/<材料名>.lesson.md     # 备课产出
    └── log/YYYY-MM-DD.md             # 每次会话一篇
```

## 安装

把 skill 目录复制到 pi 会扫描的位置：

```bash
# 用户级
cp -r learn ~/.pi/skills/
# 或项目级
cp -r learn .pi/skills/
```

然后在活动会话里 `/reload`，或重启 pi。用 `/skill:learn` 验证。

**依赖：** pi。`scripts/due.py` 需要 Python 3（仅标准库）。不需要联网、不需要 API key、
不依赖任何外部服务。

## 使用

```
/skill:learn 教我傅里叶变换
/skill:learn 我没懂 Rust 的借用检查
/skill:learn 复习软件工程
/skill:learn 继续
```

也可以直接用自然语言说——description 会负责路由。

某个主题第一次用时，skill 会采集少量上下文（为什么学、有无截止、能投入多久），
然后**先测你**。

## 实测记录：真实发生过什么

这个 skill 被用来从零教一位 C / 嵌入式工程师学软件设计（把 John Ousterhout 的
*A Philosophy of Software Design* 编译成了 38 个点的教学包）。那次运行里有三件事值得
如实汇报，因为每一件都是某个机制在起作用：

**1. 预考抓出了一个致命假设。**
教学包是从内聚 / 耦合文献编译的，而那些文献几乎全是 Java 和 C++ 写的。第一道预考题里用了
「类」这个词。学习者的回答是：*「类是啥概念？」* 他写单片机 C，从没写过面向对象代码。
**如果没有预考，我会用一套他完全没有的词汇讲完一整节课。**
> 预考的代价：一轮对话。不做预考的代价：整节课报废。

**2. 追问理由抓出了一个蒙对。**
在一道区分「控制耦合」和「标记耦合」的题上，学习者选对了——但他的理由链推不出这个结论。
常规教学会记一个 ✅ 然后翻页。这里记成了「答案对、理由错」，后面回头重做。
**这就是流畅性错觉被当场抓住。**

**3. 「哪里最薄弱」这一问，在错误观念成形前拦住了它。**
复述完概念后，学习者被问「这个解释哪里最薄弱」。他说：*「说传入参数那块，我个人感觉有点
不明确。」* 而那一点，正是他即将得出**「传结构体 = 低耦合」**这个结论的地方——一条错误
且会长期粘住的规则。**是他自己拦住的。**
两节课之后，他独立推出了两个从未教过的连接（三大复杂度症状与「已知/未知」四象限的对应关系，
以及「耦合」与「依赖」的同一性）。

### 什么**没有**被验证

把这一节写具体，比写成功更重要：

- **长期留存没有测量。** 到目前为止所有「已掌握」的判定都是**当天**的测量。间隔重复之所以
  存在，恰恰因为当天表现不能作为证据。留存数据需要以周为单位。
- **备课模式只在结构化书籍上测过**，从没在它本来为之设计的「转写稿」输入上测过（最高风险的
  材料类别）。
- **n = 1。** 一个学习者、一个主题。机制本身有已发表研究支撑；但这个 skill 对它们的**实现**
  本身并未被验证。

## 已知缺口

记录在 `SKILL.md` 里，免得以后的会话重复发现：

- **没有技能 / 练习模式。** 唱歌、调控制环、调硬件属于**程序性**技能——靠重复和即时感官反馈，
  不靠提取。把一个音高复述一遍没有意义，你必须唱出来。当前循环只处理知识类。
- **没有轻量会话路径。** 一次会话目前要读 5 个以上文件。试点阶段没问题，日常使用可能偏重。
- **外部背景采集不是一等流程。** 抓取学习者的公开背景（例如一个视频频道）对构建类比素材库
  确实很有用，但它目前会打断教学流程。
