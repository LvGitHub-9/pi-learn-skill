# 提问技巧库

`SKILL.md` 要求“讲完必须提问”“答错先问思路”。本文件回答：**具体问什么**。

原则：**提问的目的是让学习者做认知工作，不是检查他有没有在听。**
一个只要求复述的提问价值很低；一个要求解释、预测、比较、迁移的提问价值很高。

---

## 一、按认知层级选问题

从低到高。同一知识点至少走到第 4 层才算“掌握”。

| 层级 | 问法 | 例子（以“勾股定理”为例） |
|---|---|---|
| 1 回忆 | 是什么？ | 勾股定理说什么？ |
| 2 解释 | **为什么**成立？ | 为什么是 a²+b²，不是 a+b？ |
| 3 应用 | 怎么用？ | 已知两直角边 3、4，斜边多少？ |
| 4 迁移 | 换个情境还行吗？ | 如果三角形不是直角三角形呢？ |
| 5 比较/边界 | 它和 X 有什么区别？什么时候不成立？ | 余弦定理和它什么关系？ |
| 6 反例/证伪 | 能想一个反例吗？ | 能找一个 a²+b²=c² 但三角形不是直角的例子吗？ |

## 二、Rosenshine 的通用问句模板

来自 *Principles of Instruction*（2012），适合任何学科：

```
____ 和 ____ 有什么相似之处？
____ 的核心观点是什么？
____ 的优点和缺点各是什么？
____ 和 ____ 以什么方式相关？
就 ____ 而言，比较 ____ 和 ____。
你认为 ____ 的原因是什么？
____ 和我们之前学的 ____ 有什么联系？
哪一个是最好的 ____？为什么？
针对 ____ 问题，可能有哪些解法？
你同意还是不同意这句话：____ ？为什么？
关于 ____，你还有哪里没搞懂？
```

最后一条尤其好用——它比“有问题吗”有效得多，因为它要求主动定位盲区。

## 三、把“复述型”提问升级为“理解型”提问

同样的检查理解，换个问法价值差好几倍：

| ❌ 低价值 | ✅ 高价值 |
|---|---|
| 懂了吗？ | 用你自己的话讲一遍。 |
| 是不是这样？ | 为什么会这样？ |
| 记住公式了吗？ | 这个公式里每一项分别代表什么？ |
| 刚才我讲了什么？ | 如果去掉这一步，会发生什么？ |
| 这道题会做吗？ | 如果我把条件换成 X，你会怎么改？ |
| 还有问题吗？ | 关于这个点，你觉得哪里最可能让你出错？ |

## 四、答错时的追问阶梯（不要直接给答案）

按顺序推进，**每一步都等他回答**：

1. **要思路**：“你刚才是怎么想到这个答案的？”
2. **定位**：“能告诉我你是从哪一步开始不确定的吗？”
3. **给最小提示**（只给方向，不给答案）：“回到第 2 步，那里用到了什么前提？”
4. **再做一次**：“现在按你说的重新推一遍。”
5. 若仍卡住 → **拆更小**：把这一步单独拿出来，作为更小的知识点重教。

⚠️ 常见错误：用户一说“不会”，立刻开始讲解。这时要退回到第 1 步。

## 五、暴露误解的提问

误解比无知更危险，因为它已经存进长时记忆。用这些问法主动挖出来：

- **预测题**：“如果我把 X 改成 Y，你预测结果会怎样？”（然后实际做，看是否一致）
- **边界题**：“这个方法什么情况下会失效？”
- **对比题**：“它和你容易混淆的 X 有什么区别？”
- **反例题**：“能不能举一个反例？”
- **形式化题**：“如果用你自己的符号写出来，会怎么写？”
- **溯源题**：“你为什么相信这一点？有依据吗？”

依据：Rosenshine 指出，学生会在构建“心理摘要”时出错，越是没有稳固背景知识，越容易产生系统性误解；只有检查理解才能及早拦截。

## 六、自我解释与精细提问的句式

这两项是 Dunlosky 评级为**中等效用**的方法，成本极低，应该每个知识点都用：

**自我解释（self-explanation）**——让学习者对自己解释每一步：
- “这一步为什么成立？”
- “你是怎么从这一步到下一步的？”
- “这里用到了哪个已知结论？”
- “这个结论依赖什么前提？”

**精细提问（elaborative interrogation）**——追问“为什么”和“和什么有关”：
- “为什么会是这样？”
- “它和你已经会的什么连得上？”
- “如果反过来会怎样？”
- “举一个生活中的例子。”

## 七、预考的三条设计规则

预考问题必须满足：

1. **他此刻答不出来**——否则不叫预考。
2. **不是纯记忆题**——最好是要求推理或预测的。
3. **答案会在讲解中出现**——学完要能回来对上。

预考时明确告诉他：“先猜，答错完全没关系，学完我们回来对答案。”
**先不要纠正。** 记录他的原始答案，第 7 步再拿出来对照。

## 八、费曼复述的指令模板

直接照读：

> 合上材料。假设对面是一个 12 岁、完全没学过这个的人。用你自己的话讲给他听。
> 不许用“显然”“众所周知”这类词。不许用还没解释过的术语。
> 讲完之后，告诉我哪一步你自己也觉得不太踏实。

第三句是关键——它把“卡住的地方”显式化，那就是真实断点。

## 九、难度调节的问法

按 SKILL.md 第 8 步的判定决定下一题难度：

- 用户正确率太高 → 加：闭卷、限时、迁移情境、交错混合、要求举反例
- 用户正确率太低 → 减：给范例、拆步骤、提供提示清单、减少一次呈现的元素、先补前置

依据：Sweller et al. 2019（认知负荷理论）+ 2024 *QJEP* 的整合模型——低元素交互性任务加难度有益，高元素交互性任务应降负荷。

## 十、会话里的自检清单

- 我这一轮有没有提出一个**需要他思考**的问题（而不是需要他点头）？
- 他上一次开口，内容超过两句话了吗？（如果是“嗯”“对”“懂了”，说明护栏失效）
- 我是不是又连续讲了两段？
- 我给的提示，是不是直接给出了答案？
